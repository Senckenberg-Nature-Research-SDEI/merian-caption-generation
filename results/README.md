# Results

This directory stores generated outputs from the project pipeline.

## Contents

- `merian_maria_sybilla/` – OCR output produced from the source dataset.
- `merian_maria_sybilla_corrected/` – cleaned and corrected versions of the OCR results.
- `ontology/` – ontology-related output artifacts and draft data.

## Purpose

The results folder is the working output area for intermediate and final artifacts created by the text-processing and ontology-building stages.

## Notes

The project organizes outputs by the same section structure used in the source dataset, making it easier to compare raw OCR with corrected text and later pipeline outputs.
