# Data

This directory contains the source material used by the project.

## Contents

- `dataset/` – the core scanned image dataset used for OCR and downstream processing.
- `dataset.zip` – zipped archive of the dataset for convenience or offline transfer.

## Purpose

The data folder stores the raw or packaged source documents that feed the OCR, text correction, and multimodal extraction pipeline.

## Notes

The dataset is partitioned by Roman-numeral section folders and is intended to mirror the organization used in the project’s output results directories.
