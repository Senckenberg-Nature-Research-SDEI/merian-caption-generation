# Multimodal IE

This folder groups the multimodal information extraction components of the pipeline.

## Submodules

- `concept_recognition/` – identifies domain concepts from image and text signals.
- `entity_recognition/` – extracts named entities and relevant terms.
- `entity_linking/` – connects extracted entities to shared vocabularies or ontology resources.

## Purpose

This stage is intended to identify the meaningful objects, entities, and concepts described by the source material so that they can later be linked and organized into an ontology.
