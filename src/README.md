# Source code

This directory contains the project’s implementation modules and planned pipeline stages for the Merian caption-generation workflow.

## Structure

- `OCR/` – experimental OCR and document-processing code.
- `grammar_checker/` – text normalization and grammar/spelling correction utilities.
- `multimodal_IE/` – multimodal information extraction components.
- `caption_generation/` – image caption generation logic.
- `ontology_drafting/` – ontology construction and schema drafting helpers.
- `utils.py` – shared utility functions used across the repository.

## Current status

This is an active research codebase. Some components are implemented as starting points or experimental scripts, while others are placeholders for future stages of the pipeline.
