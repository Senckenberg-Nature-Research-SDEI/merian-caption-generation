# OCR

This folder contains the project’s optical character recognition and document-processing code.

## Current contents

- `llm_ocr.py` – experimental OCR workflow for extracting text from dataset images and writing structured output.

## Purpose

The OCR stage prepares source material from `data/dataset/` and produces machine-readable text or JSON output for downstream correction and extraction steps.

## Notes

This is a research-oriented implementation and may require additional model or dependency setup before it runs end-to-end.
